Elevor360D Nerja Holiday Companion V1

CUSTOMER APP: Upload index.html, guide.json, manifest.webmanifest, sw.js, both icon PNG files, elevor360d-logo.png and adverts folder to a NEW Nerja GitHub Pages repository.

MANAGER: Use the existing Universal Holiday Guide Manager; import Nerja guide.json, edit and export, then replace only Nerja guide.json on GitHub.

CLICKABLE ADVERT: Upload an image to adverts/advert.jpg, enable the advert in the manager, set the image path and an https:// website link, export guide.json and upload it.

Personal notes and photos remain on the customer device. Back up regularly. External links require internet.
